# Photos

Drop real photographs here using the exact file names below (`.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`),
then run `npm run dev` / `npm run build` — the app detects them automatically. Any slot left empty falls back
to the built-in SVG illustration, so nothing ever breaks.

Free-to-use sources: https://unsplash.com · https://www.pexels.com · https://pixabay.com  (check each photo's licence).
